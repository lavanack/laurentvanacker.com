# AVD Operations

## Guardrails

- Never restart a session host with active sessions without approval.
- Always validate available host-pool capacity before maintenance.
- Put a session host in drain mode before intervention.
- Never force-logoff active users automatically.
- Always provide a rollback procedure.
- Always cite the telemetry supporting the diagnosis.

## Incident output

Every investigation must identify:

1. User impact
2. Affected resources
3. Timeline
4. Observed facts
5. Hypotheses
6. Root cause confidence
7. Recommended action
8. Approval required
9. Rollback procedure
10. Validation queries
